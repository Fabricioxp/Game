O HOSPITAL — EDITOR WEB

Como publicar no GitHub Pages:
1. Crie/abra um repositório.
2. Coloque o arquivo index.html na raiz.
3. No GitHub: Settings > Pages.
4. Selecione Deploy from a branch.
5. Escolha a branch principal e a pasta /root.
6. Abra o endereço HTTPS do GitHub Pages.
7. No Samsung S23, vire o aparelho para a horizontal.
8. Toque em TELA CHEIA para esconder a interface do navegador.

O editor funciona em um único index.html e não depende de arquivos externos.
Projetos editáveis são salvos como .ohospital.json.
Jogos exportados são arquivos .html.

Observação: o modo Tela Cheia depende do suporte do navegador. Em HTTPS/GitHub Pages, navegadores móveis modernos normalmente permitem Fullscreen após um toque do usuário.
