O HOSPITAL — EDITOR V4

COMO PUBLICAR NO GITHUB PAGES
1. Envie todos os arquivos e pastas deste pacote para a raiz do repositório.
2. O arquivo principal é index.html.
3. Não mova css/, js/, assets/, manifest.json ou sw.js.
4. Ative GitHub Pages para a branch/pasta usada pelo repositório.

NO SAMSUNG S23
- Vire o aparelho para paisagem.
- Toque em TELA CHEIA.
- Se aparecer INSTALAR, use-o para instalar como aplicativo.
- Depois de instalado pela tela inicial, o editor abre como app (standalone), sem a barra normal do navegador.

ARQUIVOS
index.html = entrada do editor
css/styles.css = interface
js/app.js = lógica do editor
manifest.json = configuração PWA
sw.js = funcionamento offline/cache
assets/ = ícones
